# TanCar

Abkürzung für Tank + Car.
App zur Dokumentation von Tank vorgängen.

## Functionalities:
- Create Account (from root)
- Reset Passwort (from root)
- Change Passwort (per user)
- Create/Edit/delete Car
- Add tanking/refueling
    - Fuel Amount (L/kWh)
    - Odometer (km-Stand)
    - Price
    - Time/Date
    - Position
    - Notes
- Add Tripdata
    - Start km
    - End km
    - Start Time
    - End Time
    - fuel consumption
- Show Highlevel Analysis
    - Show total fuel consumption
    - show total price
    - Price per km
